# 기초

Swift는 다양한 기본 데이터 타입(String, Int, Double, Bool)과 Array, Set, Dictionary로 구성된 3개의 콜렉션 타입을 제공합니다.

익숙한 타입 이외에도 튜플(Tuple)이라는 고급 타입이 있습니다. 튜플은 값을 그룹화하여 생성하거나 전달할 수 있고 튜플을 사용하여 함수의 여러 값을 단일 복합 값으로 반환할 수 있습니다.

Swift는 값이 존재하지 않는 상태를 처리하기 위해 Optional 타입이 있습니다. Optional은 "값이 있고 X와 같다" 또는 "값이 없다."를 알려줍니다.

Swift는 타입-세이프 언어입니다. 따라서 언어가 값에 대해 타입을 명확하도록 도와주고 코드에서 같이 동작할 수 있도록 해줍니다.

<br/>

## 상수와 변수

상수와 변수는 사용하기 전에 반드시 선언 되어야 합니다.

상수는 `let` 키워드와 함께 선언하고 변수는 `var` 키워드와 함께 선언합니다.

``` swift
let constantTemp = 10	// 상수
var variableTemp = 0	// 변수
```

Swift는 여러 개의 상수 또는 변수를 선언할 때 콤마로 구분하여 한줄로 선언이 가능합니다.

``` swift
var x = 10, y = 20, z = 30
```

<br />

## 타입 명시

상수 또는 변수를 선언할 때 저장할 수 있는 값의 타입을 명확하게 하기 위해 `타입 명시`를 제공할 수 있습니다.

타입 명시는 상수 또는 변수 이름 뒤에 `콜론(:)`과 공백 한칸 뒤에 사용할 타입 이름을 적어 사용합니다.

``` swift
var name: String
var age: Int
```



같은 타입에 여러 개의 연관된 변수를 콤마로 변수 이름을 구분하고 마지막 변수 이름 뒤에 하나의 타입 명시를 통해 한줄로 선언할 수 있습니다.

``` swift
var name, address, location: String
var height, weight: Double
```

> 실제로 타입 명시가 필요한 경우는 드물긴 합니다. 상수 또는 변수를 선언할 때 초기 값을 지정하면 Swift는 해당 상수 또는 변수에 사용될 타입을 거의 항상 유추할 수 있습니다.
> 만일 초기 값을 지정하지 않을 경우에는 타입이 유추되지 않기 때문에 타입을 명시하는게 좋습니다.

<br />

## 상수와 변수의 이름

상수와 변수 이름은 유니코드(Unicode) 문자를 포함하여 대부분의 문자를 포함할 수 있지만 일반적으로 다음과 같은 규칙을 따릅니다.

공백, 수학적 기호, 화살표, 내부에서 사용하는 유니코드 스칼라 값, 선과 박스를 그리는 문자를 포함할 수 없으며 숫자로 시작하는 형태로는 상수와 변수 이름을 선언할 수 없습니다.

> 만일 Swift에서 제공하는 `키워드(var, let 등)`와 동일한 이름의 상수 또는 변수를 제공해야 한다면 이름을 백틱(`)으로 묶어야 합니다. 그리고 웬만하면 키워드와 동일한 이름으로 상수 또는 변수를 제공하지 않는게 좋습니다.

변수와 달리 상수 값은 지정된 이후에는 변경할 수 없습니다. 값을 변경하려고 하면 코드가 컴파일 될 때 오류가 발생합니다.

``` swift
let constantName = "constant"
constantName = "variable" 			// 오류
```

## 상수와 변수 출력

Swift는 `print('상수 또는 변수')` 형태로 상수 또는 변수의 현재 값을 출력할 수 있습니다.

``` swift
let name = "David";

print(name)
// "David"
```

> print 함수는 하나 또는 그 이상의 값을 적절하게 출력하는 전역함수이며 Xcode에서 콘솔창에 결과를 출력합니다.

Swift는 긴 문자열에 상수 또는 변수를 포함하여 출력할 때 `문자열 삽입`을 사용합니다.

이름을 소괄호로 감싸고 여는 소괄호 전에 역슬래시를 추가해야 합니다.

``` swift
let name = "David";

print("My name is \(name)")
// "My name is David"
```

## 주석

코드에서 설명 또는 기록을 위해 실행되지 않는 문자를 추가할 때 주석을 사용합니다.

주석은 코드가 컴파일 될 때 Swift 컴파일러에 의해 무시됩니다.

Swift에서 주석을 사용하는 방법은 C언어와 유사합니다. 한줄 주석은 슬래시 2개`(//)`로 시작합니다.

``` swift
// 한 줄 주석입니다!
```



여러 줄 주석은 슬래시 뒤에 애스터리스크`(/*)` 로 시작하고 애스터리스크 뒤에 슬래시`(*/)`로 끝납니다.

``` swift
/* 여러 줄 주석입니다1
여러 줄 주석입니다2 */
```



Swift는 여러 줄 주석 안에 다른 여러 줄 주석을 중첩시킬 수 있습니다. 여러 줄 주석 블럭을 시작한 후에 첫번째 블럭 내에서 두번째 여러 줄 주석을 시작하여 중첩된 주석을 작성하는 방식입니다.

``` swift
/* 중첩된 주석입니다1
	/* 중첩된 주석입니다.2 */
중첩된 주석입니다.3 */
```

> 중첩 주석을 사용하면 이미 여러 줄 주석이 포함되어 있어도 큰 코드 블럭을 빠르고 쉽게 주석 처리 할 수 있습니다.

## 세미콜론

다른 프로그래밍 언어들과 달리 Swift는 코드의 각 구문 후에 세미콜론`(;)`이 필수조건은 아닙니다.

다만 여러 구문을 한줄로 작성할 경우에는 세미콜론을 필수로 작성해야 합니다.

``` swift
// 다음과 같이 한줄에 변수 선언 및 print 함수를 통한 출력을 작성해야 하는 경우엔 세미콜론 필수
let name = "David"; print(David)

// 다음과 같이 각각의 구문을 한 줄씩 작성할 경우엔 세미콜론을 작성하지 않아도 됨
let name = "David"
print(David)
```
